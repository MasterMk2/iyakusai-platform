# Original fanfare asset

`original_fanfare.wav` is an original procedural score (brass, timpani, cymbal and room reflection)
made for this Bot's fanfare video feature. No commercial recording, external composition or sampled
instrument was used. Its identity and the 4.80-second title impact are in `audio_manifest.json`.
It is distributed under the same MIT License as the rest of this repository.

Pillow is an optional external renderer dependency under its HPND license:
https://pillow.readthedocs.io/en/stable/about.html#license
FFmpeg is an external executable, not bundled here. A build that enables GPL/version3 and libx264
carries the matching notice and source obligations if a binary is ever redistributed:
https://ffmpeg.org/legal.html
https://ffmpeg.org/ffmpeg.html

Fonts are installed and selected on the worker host. No font file is redistributed here. For Linux,
a locally installed Japanese Noto CJK font is suitable; keep its own license if a separate
distribution bundles it.
