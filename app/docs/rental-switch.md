# 物品貸出を止める・再開する（2026-11-09）

しばらく物品貸出を使わない間、権限管理者が **設定 › 委員会の運営 › 使う機能** で止められます。台帳・権限・写真は消えず、再開すれば止める前と同じに使えます。

## 止めると変わること

- 上のタブから「物品貸出」が消え、ホームの「物品貸出」の欄と、対応が必要な件数の「返却待ちの団体」「要確認の物品」が出なくなります。当日の欄の「物品の状況」も出ません。
- 物品のスマホ画面（`/rental`、QR ラベル・カードから開く `/i/<個体コード>`）と回収表（`/rental/supplies`）は「物品貸出は停止中です」と出し、カメラと読み取りを始めません。返却チェックシート（`/rental/print`）も一覧を読み込めません（API が止まるため）。
- `/api/rental/` の API は、次を除いて **503・`code: "rental_paused"`** を返します。読み取りも書き込みも止まります。
  - `GET /api/rental/me`（`enabled: false` を返し、画面が停止中と分かるようにする）
  - 権限管理者の設定（`/api/rental/admin/access`、`/api/rental/admin/permissions`、`/api/rental/admin/switch`）。止めている間に権限を整えておけます。
- 止める前にスマホに保留していた登録は、その端末に残ります。再開したあとに送れます。

## 変わらないこと

- Google ドライブへの複製、年度の切り替え、Bot が読む物品の情報（`/v1/bot/datasource` の rental）はそのままです。
- 権限管理者でない人は切り替えられません（物品管理者でも不可）。

## 置き場所

- `rental.sqlite3` の `config` 表の `rental_enabled`（`true`／`false`）。**無いときは使用中**なので、この版を出しただけでは何も変わりません。
- 切り替えの記録は `rental_switch_events`（日時・した人・オンかオフか）。権限の変更記録（`rental_access_events`）とは分けています。前の版の権限の画面がこの記録を読み違えないためです。
- API：`GET /api/rental/admin/switch`（状態・いま貸出中と要確認の件数・最近 20 件の切り替え）、`PUT /api/rental/admin/switch`（`{"enabled": true|false}`。同じ値なら何も記録しない）。

## 前の版に戻すとき

前の版はこの設定を読まないので、止めたまま前の版に戻すと物品貸出は使える状態に戻ります（`rental_enabled` の値は残り、この版に戻すとまた止まります）。
