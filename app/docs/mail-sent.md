# 送信箱

委員会のメール（`SMM_AUTH_MODE=discord` の受信箱）に、委員会が送ったメールの一覧を足したものです（2026-11-23）。委員会のアドレスから送った分と、委員の個人アドレスから送った分が載ります。メールのタブの左の列の「送信」の中にあります（幅の狭い画面では、一覧の上の「送信」の並び）。

## 1. 載るもの

| 送り方 | 載り方 |
|---|---|
| このアプリから送った | 送った委員の名前つき。状態は「送信済み」「送信中」「送信できたか不明」「送れなかった」 |
| Gmail から直接送った（受信箱のアドレスを差出人にして） | 取り込まれてから載る（約 10 分ごと）。だれが送ったかは分からないので「Gmail から送信」と出す |
| 委員の個人アドレス（委員会のドメイン）から送った | 取り込まれた分が載る（委員会のグループあての連絡も含む）。差出は「個人のアドレス」。送った人は、設定 › 署名の「本人のアドレス」にそのアドレスを入れた委員の名前。だれも入れていなければ、メールにある名前（無ければアドレス） |

載せないもの：

- 差出人が受信箱のアドレスでも、表示名が「◯◯ via ＜グループ名＞」のメール。Google グループが、グループあてに届いたメールの差出人をグループのアドレスに書き換えたもので、書いたのは別の人（委員会の外の人が多い）です。受信箱にはこれまでどおり載ります。
- 委員会のドメインの外のアドレス（個人の Gmail など）から送ったメール。
- 承認待ち・差し戻しのメール。まだ送っていないので、「承認待ち」の一覧にあります（承認されて送られると、書いた人の名前で送信箱に載ります）。

### 送れなかった・送信できたか不明

アプリは送る前の件名・本文を保存しない作りなので、この 2 つの行には件名と本文がありません。出るのは時刻・差出の受信箱・宛先の件数・送った人だけです。返信だったときは、返信先のスレッドを開けます。

- **送れなかった**：メールサーバーが受け付けなかったもの。理由（宛先が受け付けられなかった など）を出します。相手には届いていません。
- **送信できたか不明**：送る途中で接続が切れたもの。届いている可能性があるので、もう一度は送らず、相手か委員会の Gmail の送信済みで確かめます。あとで Gmail の写しが取り込まれると（同じ Message-ID）、送信済みの行に変わります。
- 「送信中」のまま 10 分を過ぎたもの（アプリが途中で止まったもの）も「送信できたか不明」として出します。

## 2. 見られる人

メールを読める委員全員です（送信の権限が無くても見られます）。送れなかった分・送信できたか不明の分も全員に出し、送り直さずにやめた分も消さずに残します。個人アドレスから送った分は、委員会のグループあての連絡も含めてすべて載せます（どれも 2026-11-23 に決定）。

- BCC のアドレスは出しません。宛先の件数にだけ数えます（このアプリから送った分）。
- 認証メールの件名は、受信箱と同じく権限管理者のほかには出しません。

## 3. 一覧

- 1 通 1 行で、送った時刻の新しい順です。相手から返信が来ても並びは動きません。
- 行を押すと、右（スマホでは一覧の代わり）にそのスレッドが開き、相手からの返信もそこで読めます。
- 絞り込み：差出（受信箱・委員の個人アドレス）・送った人（自分が送った）・状態（送信できたか不明・送れなかった）・検索（件名・宛先・本文）。件名の残っていない行は、検索には出ません。「自分が送った」には、署名に入れた本人のアドレスから送った分も入ります。
- 表示件数は、受信箱の一覧と同じ設定を使います。

## 4. 作り

- `GET /api/mail/sent`（`mailboxId`・`personal=1`・`q`・`mine=1`・`state=problem`・`page`・`pageSize`。`mailboxId` と `personal` は同時に指定できない）。`/api/mail/status` に `sentBox: true` があるサーバーでだけ、画面に入口を出します（古いサーバーでは出ません）。
- 表・列・索引は足していません。`mail.sqlite3` の `messages` と `outgoing`（送信の記録）を読むだけなので、反映のときに許す表の一覧を変えなくてよいです。
- 差出人のアドレスが委員会のドメイン（別名のドメインを含む）のメールを毎回すべて読み、受信箱のアドレスか（`+` の付いたもの・別名のドメインも同じ扱い）、委員の個人アドレスかを分けます。年に数千通の規模を前提にしています。
- 個人アドレスと委員の結び付けは、署名の設定（`signatures.json`）の「本人のアドレス」です。同じアドレスを 2 人が入れていたら、だれとも結び付けません。
- 画面の URL は `#/all?sent=1`（差出に受信箱を選ぶと `#/mailbox/<id>?sent=1`。個人アドレスは一覧の絞り込みで、URL には出ない）。スレッドを開くと `&thread=` が付きます。
- 試験：`tests/mailbox/sent.test.ts`（サーバー）・`tests/e2e/mail-sent.spec.ts`（画面）。
